# Java_assignment1 E-Commerce Website

##  Project Overview

This project is a Java-based E-Commerce Website developed to demonstrate the fundamentals of web application development. It provides an online shopping platform where users can browse products, manage their shopping carts, and proceed with the checkout process.

The application also includes administrative features for managing products, categories, and sales records.

##  Features

### User Features
- User Registration and Login
- Browse Available Products
- View Product Details
- Add Products to Shopping Cart
- Update Product Quantities
- Checkout Functionality
- View Shopping History

### Admin Features
- Manage Products
- Manage Product Categories
- View Sales History
- Manage Store Inventory

##  Requirements

- Java Development Kit (JDK)
- Apache Maven
- MySQL Server
- Apache Tomcat
- Eclipse IDE or IntelliJ IDEA

## Getting Started

1. Clone or download the repository.
2. Extract the project files.
3. Import the project into your Java IDE as a Maven project.
4. Configure the MySQL database connection.
5. Update the database credentials in the project configuration.
6. Resolve Maven dependencies.
7. Configure Apache Tomcat.
8. Run the application on the server.

##  Project Objective

The main objective of this project is to understand how Java technologies are used to develop a web-based shopping application, including user authentication, database operations, product management, and e-commerce functionality.
